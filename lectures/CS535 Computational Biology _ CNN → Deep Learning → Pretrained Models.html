1. Course Goal: Learn to Conduct Machine-Learning Research, Not Just Run a CNN

This module starts with Cats vs. Dogs classification so students can clearly observe the deep-learning research workflow without a heavy biological prerequisite. By the end, students should be able to transfer the same experimental design principles to protein sequences, functional prediction, and other computational-biology problems.

Scientific question ↓ Dataset construction / quality control ↓ Train / validation / independent test ↓ Baseline CNN ↓ Controlled architecture & hyperparameter experiments ↓ Modern deep learning architectures ↓ Pretrained model / transfer learning ↓ Independent challenge & OOD test ↓ Error analysis + statistical interpretation ↓ Academic report
Core rule:Change only the main experimental variable at a time. Use the validation set for model and hyperparameter selection; use the independent test set only for final evaluation, never for repeated tuning.

Students Must Be Able to Calculate Parameter Counts

For a convolution layer with input channels = 3, kernel = 3×3, and output filters = 32:

parameters = (3 × 3 × 3 + 1 bias) × 32 = 896

Students should be able to estimate parameter count, feature-map size, and GPU-memory requirements from the architecture instead of treating the CNN as a black box.

3A. Based on Hung-yi Lee’s CNN Course: First Ask “Why Do We Need CNNs?”

This course adopts the conceptual progression used in Hung-yi Lee’s CNN lectures: rather than memorizing APIs first, derive the CNN architecture from structural observations about images.

Observation 1: Important patterns are usually local → Receptive Field / Local Connectivity

To recognize a cat, a neuron does not necessarily need to see the entire image at once. Ears, eyes, fur texture, and contours can first be captured by local pattern detectors, so CNN neurons operate on local receptive fields.

Observation 2: The same pattern may appear anywhere → Parameter Sharing / Convolution

The same detector should work at different image locations. CNNs reuse the same kernel weights across positions, producing a feature map while dramatically reducing the number of parameters.

Observation 3: Moderate subsampling often preserves object identity → Pooling / Downsampling

Pooling reduces spatial resolution and computation while increasing effective receptive field, but pooling is not mandatory for every task; architecture design must depend on the data and objective.

Teaching sequence:Problems with fully connected networks → local receptive fields → stride/overlap/padding → parameter sharing → filters/feature maps → multiple convolution layers → pooling → complete CNN → augmentation and invariance limitations.

Feature Maps and Multi-Layer CNNs

For RGB input, a nominal 3×3 filter is actually 3×3×3. If the first layer outputs 64 feature maps, each filter in the next layer spans all 64 channels and therefore has shape 3×3×64.

For RGB input, each kernel is not merely 3×3; it is 3×3×3 because it must read the R, G, and B channels simultaneously. If the layer has 64 filters, the output contains 64 feature maps.

RGB input 224 × 224 × 3 ↓ 64 kernels each = 3 × 3 × 3 ↓ 64 feature maps 224 × 224 × 64 (with SAME padding, stride 1)

Step 6. What Does It Mean to Say “Each Kernel Represents a Pattern”?

In this teaching example, we manually define vertical-edge, horizontal-edge, and bright-region filters, so their meanings are explicit. In a real CNN, kernel weights are learned from data through backpropagation. A more precise statement is:

Each learned kernel can be viewed as a pattern detector.
Shallow filters often respond to low-level patterns such as edges, orientation, color contrast, and texture. Deeper filters combine multiple earlier feature maps and may respond to more complex shapes and local structures. However, a deep kernel is not necessarily interpretable as a human-named “ear filter” or “eye filter.”

The core idea of a CNN is therefore:

many local pattern detectors ↓ many feature maps ↓ combine simple patterns ↓ higher-level patterns ↓ classification

This is what “multiple convolution kernels” really means: the first layer does not turn an image into one feature map, but into many. For example, with 32 filters:

28 × 28 × 1 ↓ 32 kernels, each 3 × 3 × 1 ↓ 28 × 28 × 32

At the second layer, if the input already has 32 channels, each new 3×3 kernel is actually:

3 × 3 × 32

If the second layer has 64 filters, the output is:

28 × 28 × 64

How Does This Connect to the Idea That Each Kernel Is a Pattern Detector?

For MNIST, shallow filters are easy to interpret as:

vertical stroke detectordetecting vertical strokes such as those in 1, 4, and 7.
horizontal stroke detectordetecting horizontal strokes such as those in 2, 5, and 7.
curve / corner detectordescribing curves and turns in digits such as 0, 2, 3, 5, 6, 8, and 9.
local density / blob detectordescribing whether strokes are locally concentrated.

The second layer no longer reads raw pixels directly. Instead, it sees the multiple feature maps produced by the first layer, allowing simple patterns to be combined into more complex local structures. For example:

vertical stroke + horizontal stroke + corner response ↓ a more complex "top-left bend" pattern ↓ higher-level digit representation
Good in-class question:If digit 5 has a strong top horizontal stroke, a strong left vertical stroke, and a curved lower region, which filters might activate simultaneously? How would the feature-map combination differ for digit 1?

Output-Size Formula

H_out = floor((H_in + P_top + P_bottom - dilation×(K-1) - 1) / stride + 1)

Odd kernels can preserve size with symmetric padding. Even kernels require asymmetric left/right or top/bottom padding to achieve exact SAME output. The notebook therefore includes a custom SamePadConv2d implementation.

Why Do Many CNNs Prefer Small Kernels?

Classic CS231n sizing guidelines emphasize small filters such as 3×3 (and commonly up to 5×5), stride 1, and size-preserving padding. VGG further demonstrated increasing depth with stacked 3×3 convolutions. With the same channel count C, three 3×3 layers require about 27C² weights, whereas one 7×7 layer requires 49C²; the stacked design also inserts additional nonlinearities.

Research principle:This does not mean “3×3 is always best.” Students must actually plot kernel size from 1–10 against performance, parameter count, and runtime.

7. Evaluation Metrics: Accuracy Is Not Enough

For binary classification, begin with the confusion matrix:

Predicted DogPredicted Cat
Actual DogTPFN
Actual CatFPTN
AccuracyBalanced Accuracy PrecisionRecall / Sensitivity SpecificityF1-score ROC-AUCPR-AUC / Average Precision MCCBrier Score TP / TN / FP / FN

Core Formulas

Accuracy    = (TP + TN) / (TP + TN + FP + FN)
Precision   = TP / (TP + FP)
Sensitivity = TP / (TP + FN)
Specificity = TN / (TN + FP)
F1          = 2 × Precision × Recall / (Precision + Recall)

ROC-AUC measures the TPR/FPR trade-off across thresholds. PR-AUC is often more informative under class imbalance or when the positive class is particularly important. MCC uses information from all four cells of the binary confusion matrix and is a valuable complementary metric.

Extension:Compare threshold = 0.5 with a threshold selected on the validation set, and explain why the test set must not be used to choose the threshold.

8. Build a Hard / OOD Challenge Set: Does the Model Really Generalize?

Each group should collect or generate at least 40–60 additional images, while the instructor keeps a separate hidden challenge set. Recommended cases include:

OcclusionOnly part of the animal is visible or it is occluded by furniture.
ScaleThe animal is extremely small or photographed at extreme close range.
IlluminationLow light, backlighting, or high contrast.
Motion / BlurBlur or fast motion.
ViewpointRear view, top-down view, or unusual pose.
Rare breedsUnusual-looking cat or dog breeds.
Mixed sceneCat and dog appear in the same scene.
OODFoxes, wolves, tigers, stuffed animals, statues, and cartoons.

OOD images should not be evaluated with ordinary binary accuracy because the model was trained only on cat/dog classes. Students should examine confidence, entropy, high-confidence errors, and discuss the limitations of a closed-set classifier.
