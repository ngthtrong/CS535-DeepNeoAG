1. Why IMDb is the ideal second project

After image CNNs, IMDb removes one spatial dimension but preserves the same core idea: a convolutional filter scans a local neighborhood and responds when a useful pattern is present.

Image CNN
image ↓ 2D local patch ↓ Conv2D kernel ↓ visual pattern ↓ feature map
Text CNN
token sequence ↓ local word/subword window ↓ Conv1D kernel ↓ phrase pattern ↓ feature map
Course goal: students should discover that CNN is not an “image-only” model. It is a local pattern detector over an ordered representation.

Example: the phrase not very good is a 3-token local pattern. A Conv1D filter with window size 3 can learn to respond strongly to combinations like this without explicitly hard-coding the phrase.

3. IMDb dataset

The Hugging Face IMDb dataset contains 25,000 labeled training reviews, 25,000 labeled test reviews, and an additional 50,000 unlabeled reviews. The official Hugging Face text-classification tutorial uses IMDb to demonstrate DistilBERT sentiment classification.

review text → tokenizer → token IDs / embeddings → sequence model → positive or negative
Research practice: create a validation split from the training set. Keep the official test set untouched until architecture and hyperparameters are chosen.

4. Baseline: learned word embeddings + simple 1D CNN

review ↓ simple tokenizer ↓ vocabulary IDs ↓ Embedding(vocab_size, 128) ↓ Conv1D ↓ Global Max Pool ↓ binary classifier

This baseline is intentionally not pretrained. It answers: how much can local phrase patterns learn from the task data alone?

5. Multi-window 1D CNN

A single window size assumes one useful phrase length. A multi-window CNN allows several local scales to be learned simultaneously.

L × D embedding ├─ Conv1D window 2 ─ max pool ┐ ├─ Conv1D window 3 ─ max pool ┤ ├─ Conv1D window 4 ─ max pool ┤ → concatenate → classifier └─ Conv1D window 5 ─ max pool ┘
WindowInterpretation
2short bigram-like local interactions
3short phrase patterns
4–5longer compositional local sentiment patterns

6. Why add a pretrained language model?

Random or task-trained word embeddings assign one representation to a token. A contextual language model such as DistilBERT generates token representations that depend on surrounding context.

Static / task embedding
bank → one vector
Contextual embedding
river bank   → vector A
bank account → vector B
This is the conceptual step that later becomes a Protein Language Model: amino-acid representations can also become context dependent.

7. DistilBERT + multi-window CNN

review ↓ DistilBERT tokenizer ↓ DistilBERT hidden states L × 768 ↓ transpose to 768 × L ↓ multi-window Conv1D 2 / 3 / 4 / 5 ↓ global max pooling ↓ sentiment classifier

For teaching, first freeze DistilBERT and train only the CNN head. Then optionally unfreeze the language model for full fine-tuning.
