2. Biological prediction problem

Neoantigens are mutation-derived tumor-specific peptide candidates that can be recognized by the immune system under appropriate presentation and immune-context conditions. DeepNeoAG focuses on sequence-based neoantigen epitope prediction and was designed to operate without requiring MHC allele information as model input.

Important biological boundary: predicting a peptide as neoantigen-like is not equivalent to proving that it is naturally processed, presented by a patient's HLA, recognized by T cells, or clinically effective. The computational endpoint must be stated precisely.

3. What the published DeepNeoAG framework does

The 2024 DeepNeoAG study combines pretrained Protein Language Model representations with multi-window scanning convolutional neural networks. The public repository provides feature-generation paths for ProtTrans, TAPE, and ESM and includes a documented ESM-2 650M extraction example.

peptide sequence ↓ PLM per-residue representation ↓ local multi-window Conv1D feature extraction ↓ feature integration ↓ neoantigen vs other

6. Why start with a one-hot baseline?

peptide ↓ 20-aa one-hot representation L × 20 ↓ Conv1D / MCNN ↓ classifier

A one-hot model isolates what can be learned from sequence order and supervised labels without pretrained biological knowledge. Without this baseline, it is difficult to quantify how much improvement comes from the PLM.

7. ESM-2 per-residue embeddings

The archived ESM repository documents multiple ESM-2 checkpoints. For example, esm2_t33_650M_UR50D has 33 transformer layers, about 650M parameters, and 1280-dimensional embeddings. The repository's extraction tools distinguish per_tok residue-level embeddings from mean-pooled sequence embeddings.

S L Y N T V A T L ↓ ESM-2 9 residues × D dimensions ↓ L × D contextual residue matrix

For classroom execution on a T4, a smaller checkpoint such as esm2_t6_8M_UR50D is useful for demonstrating the complete pipeline quickly. Research reproduction should return to the published feature protocol.

8. Multi-window CNN over PLM embeddings

L × D ESM/PLM embeddings ├─ window 2 → filters → pool ┐ ├─ window 4 → filters → pool ┤ ├─ window 8 → filters → pool ┤ → concatenate → classifier └─ window 16 → filters → pool┘

The precise window set should be treated as a model hypothesis about useful local scales. A window is not automatically a biological motif; motif-like interpretation requires additional evidence.

9. Tensor shapes: the computational core

ESM output:           [B, L, D]
transpose for Conv1D: [B, D, L]
Conv1D output:        [B, F, L']
global max pooling:   [B, F]
multiple windows:     concatenate several [B, F] blocks

This is almost identical to the DistilBERT + MCNN pipeline from IMDb. That similarity is the main pedagogical reason to place these projects back-to-back.

10. Class imbalance is now a central scientific issue

After filtering, the repository contains 302 neoantigens and 6,710 other peptides—roughly one positive for every 22 negatives.

Why accuracy can mislead: a classifier that predicts every sequence as “other” already achieves very high accuracy while having zero sensitivity for neoantigens.

Use class-weighted loss or carefully designed sampling as experiments, and always report precision-recall behavior.

11. Sequence similarity leakage

Bioinformatics models can appear strong when highly similar sequences occur across train and test sets. DeepNeoAG's public dataset table explicitly reports filtering below 30% sequence similarity before the final dataset.

raw peptide candidates ↓ similarity / redundancy control ↓ train-test separation ↓ model development ↓ independent evaluation
Research lesson: similarity control is analogous to preventing near-duplicate images from appearing in both train and test—but in protein sequence research the biological consequences can be much stronger.

14. How far can we interpret MCNN filters?

A high-activation local window may suggest a sequence pattern important to prediction, but predictive activation does not automatically prove a biochemical binding motif or immune-recognition mechanism.

learned filter ↓ collect top-activating peptide windows ↓ sequence-logo / residue enrichment analysis ↓ compare with known biology ↓ form cautious biological hypothesis ↓ experimental validation if mechanistic claim is required
