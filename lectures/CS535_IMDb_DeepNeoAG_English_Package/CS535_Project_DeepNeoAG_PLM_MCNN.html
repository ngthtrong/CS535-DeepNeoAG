1. Why DeepNeoAG is the ideal first biological project

DeepNeoAG is conceptually close to the IMDb exercise: both are short token sequences, both benefit from pretrained contextual representations, and both can use multi-window 1D CNNs to detect task-relevant local patterns.

IMDb review ↓ language model ↓ token embeddings ↓ multi-window Conv1D ↓ sentiment ⇩ same computational idea ⇩ peptide sequence ↓ protein language model ↓ residue embeddings ↓ multi-window Conv1D ↓ neoantigen prediction

2. Biological question

Neoantigens arise from tumor-specific mutations and may trigger anti-tumor immune responses. DeepNeoAG was designed to predict neoantigen epitopes directly from peptide sequence information while avoiding an explicit requirement for MHC-allele input.

Teaching question: Can a model learn biologically useful sequence patterns directly from peptide “language,” and does PLM pretraining improve those representations?

3. Published DeepNeoAG dataset design

The public DeepNeoAG repository reports 32,877 initial epitope sequences. After sequence-similarity filtering to below 30% and restricting length to <35 residues, 7,012 sequences remained: 302 neoantigens and 6,710 “other” peptides. The repository reports an 80/20 training/testing split of 5,608 / 1,404 samples.

5. Start with a transparent baseline

peptide ↓ 20-aa one-hot encoding L × 20 ↓ Conv1D ↓ Global Max Pool ↓ binary classifier

This model is intentionally simple. It asks whether local sequence patterns can be learned without a pretrained biological representation.

6. Protein Language Model representation

The published repository supports ProtTrans, TAPE, and ESM feature generation; its example ESM command uses esm2_t33_650M_UR50D and per-token representations. The paper describes combining global sequence-level PLM information with local features from a multi-window CNN.

peptide: S L Y N T V A T L ↓ Protein LM ↓ contextual residue vectors L × D ↓ Conv1D
Key idea: “L” still means sequence length, exactly as in text. The difference is that the token alphabet is amino acids rather than words/subwords.

7. Multi-window scanning CNN

PLM residue embeddings L × D ├─ Conv1D window 2 ─ pool ┐ ├─ Conv1D window 3 ─ pool ┤ ├─ Conv1D window 4 ─ pool ┤ ├─ Conv1D window 5 ─ pool ┤ → concatenate → classifier └─ Conv1D window 8 ─ pool ┘

Different windows test whether useful biological patterns exist at different local sequence scales. In a research report, students should not claim that a window directly equals a biological motif unless interpretability evidence supports that conclusion.

8. Classroom model: DeepNeoAG-Lite

The original repository provides larger PLMs and precomputed-feature workflows. For a T4 classroom, the accompanying Colab first uses a smaller ESM-2 model so students can observe the full process end-to-end.

9. Research rigor specific to peptide prediction

Similarity leakageNear-identical peptides across train/test can inflate performance. The repository explicitly reports <30% similarity filtering.
Class imbalanceUse class-weighting or sampling carefully, and report metrics that reflect the minority positive class.
Independent testDo not tune thresholds, windows, or filters on the final test set.
Negative definition“Other” peptides are not automatically perfect biological negatives; discuss label quality.
Peptide lengthPadding and masking must not create artificial patterns.
External validationFuture extension should test across cancer types / cohorts, not only the original domain.

10. Evaluation metrics

Sensitivity / RecallSpecificityPrecisionF1MCCROC-AUCPR-AUCTP/TN/FP/FN

Do not optimize for accuracy alone. With ~1 positive for every ~22 negatives, a trivial majority-class classifier already has high accuracy.
